# Move Zeroes – Using Extra Array in Java

This solution demonstrates a simple and clear approach to the classic Move Zeroes problem by using an auxiliary array. The goal is to move all zeroes to the end while maintaining the relative order of non-zero elements.

## Problem Statement

Given an integer array nums, move all 0s to the end of the array without changing the relative order of the non-zero elements.

- The operation must be done in-place (final result stored in nums).
- Order of non-zero elements must remain the same.

## Source Code

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        int[] temp = new int[n];
        int j = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) {
                temp[j] = nums[i];
                j++;
            }
        }

        int k = 0;
        for (int i = 0; i < n; i++) {
            if (k == j) {
                nums[i] = 0;
            } else {
                nums[i] = temp[k];
                k++;
            }
        }
    }
}
```

## Example

Input:

nums = [0, 1, 0, 3, 12]

Output:

[1, 3, 12, 0, 0]

## Time and Space Complexity

- Time Complexity: O(n)
- Space Complexity: O(n) (extra array used)

# Move Zeroes – In-Place Two Pointer Approach in Java

This solution solves the Move Zeroes problem using an in-place two-pointer technique, which achieves optimal space complexity while preserving the relative order of non-zero elements.

## Problem Statement

Given an integer array nums, move all 0s to the end of the array without changing the relative order of the non-zero elements.

- The operation must be done in-place.
- No extra array should be used.

## Source Code

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int i = 0;
        int n = nums.length;
        int j = 0;

        for (; j < n; j++) {
            if (nums[j] != 0) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
                i++;
            }
        }
    }
}
```

## Example

Input:

nums = [0, 1, 0, 3, 12]

Output:

[1, 3, 12, 0, 0]

## Time and Space Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

# Leetcode-121 Best Time to Buy and Sell Stock – Brute Force vs Optimized (Java)

This document explains two commonly used approaches to solve the Best Time to Buy and Sell Stock problem:

- A brute force approach using nested loops
- An optimized single-pass approach using minimum buying price

Both approaches are important for understanding problem-solving progression in DSA.

---

## Problem Statement

You are given an array prices where prices[i] represents the stock price on the i-th day.

You want to maximize profit by choosing one day to buy and a later day to sell.

- At most one transaction is allowed
- If no profit is possible, return 0

---

## Approach 1: Brute Force Solution

This approach checks all possible buy–sell pairs and keeps track of the maximum profit.

### Source Code

```java
class Solution {
    public int maxProfit(int[] prices) {
        int current_Profit = 0;
        int n = prices.length;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (prices[j] - prices[i] > current_Profit) {
                    current_Profit = prices[j] - prices[i];
                }
            }
        }
        return current_Profit;
    }
}
```

### Explanation

- The outer loop selects the buying day.
- The inner loop selects the selling day.
- Profit is calculated for every valid pair.
- The maximum profit is stored in current_Profit.

### Complexity Analysis

- Time Complexity: O(n²)
- Space Complexity: O(1)

---

## Approach 2: Optimized Single-Pass Solution

This approach tracks the minimum buying price so far and calculates profit in one traversal.

### Source Code

```java
class Solution {
    public int maxProfit(int[] prices) {
        int current_Profit = 0;
        int n = prices.length;
        int buying_price = prices[0];

        for (int i = 1; i < n; i++) {
            if (buying_price < prices[i]) {
                if (prices[i] - buying_price > current_Profit) {
                    current_Profit = prices[i] - buying_price;
                }
            } else {
                buying_price = prices[i];
            }
        }
        return current_Profit;
    }
}
```

### Explanation

- buying_price stores the lowest price seen so far.
- For each day, potential profit is calculated using the current price.
- If a lower price is found, update buying_price.
- Maximum profit is updated in a single pass.

### Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)
