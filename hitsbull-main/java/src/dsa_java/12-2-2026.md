# Zigzag Subarray in Java

This Java program finds the length of the longest zigzag subarray.

## ✅ Zigzag Condition
A subarray is considered zigzag if:
- Elements at **odd index difference** are greater than the previous element.
- Elements at **even index difference** are smaller than the previous element.

---

## 💻 Source Code

```java
public class Main {

    static int zigzagsubarray(int[] num) {
        int ans = 1;
        int n = num.length;

        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {

                int len = j - i + 1;
                int flag = 1;

                // Check for zigzag condition
                for (int k = 1; k < len; k++) {
                    if (k % 2 == 1 && num[i + k] > num[i + k - 1]) {
                        continue;
                    }
                    else if (k % 2 == 0 && num[i + k] < num[i + k - 1]) {
                        continue;
                    }
                    else {
                        flag = 0;
                    }
                }

                if (flag == 1) {
                    if (len > ans) {
                        ans = len;
                    }
                }
            }
        }

        return ans;
    }

    public static void main(String[] args) {
        int[] arr = {12, 13, 1, 5, 4, 7, 8, 10};
        System.out.println(zigzagsubarray(arr));
    }
}
```

---

## 📌 Example Input
```
12, 13, 1, 5, 4, 7, 8, 10
```

## 📌 Output
```
Length of longest zigzag subarray
```

---

## 📝 Time Complexity
- **O(n³)**  
  (Three nested loops)

# Rotate Array - Optimal Solution (Reversal Algorithm)

## Problem
Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

---

## ✅ Java Implementation

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        
        // Edge case
        if (n == 0) return;

        k = k % n;  // Handle k greater than n
        
        // Step 1: Reverse whole array
        reverse(nums, 0, n - 1);
        
        // Step 2: Reverse first k elements
        reverse(nums, 0, k - 1);
        
        // Step 3: Reverse remaining elements
        reverse(nums, k, n - 1);
    }
    
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }
}
```

---

## ⏱ Time Complexity
- O(n)

## 💾 Space Complexity
- O(1)
