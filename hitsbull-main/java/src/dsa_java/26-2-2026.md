# Copy List with Random Pointer(Leetcode-138)

## Problem
Given a linked list where each node contains an additional random pointer
that could point to any node in the list or null, return a deep copy of the list.

---

## Java Implementation (Brute Force Approach)

```java
/*
 // Definition for a Node.
 class Node {
     int val;
     Node next;
     Node random;

     public Node(int val) {
         this.val = val;
         this.next = null;
         this.random = null;
     }
 }
*/

class Solution {
    public Node copyRandomList(Node head) {
        
        Node Head = null;
        Node Tail = null;
        Node curr = head;

        // Step 1: Create a copy of the list (without random pointers)
        while (curr != null) {
            Node newNode = new Node(curr.val);

            if (Head == null) {
                Head = newNode;
                Tail = newNode;
            } else {
                Tail.next = newNode;
                Tail = newNode;
            }

            curr = curr.next;
        }

        // Step 2: Assign random pointers
        curr = head;
        Node ptr = Head;

        while (curr != null) {
            int idx = 1;
            Node temp = head;

            while (temp != curr.random) {
                temp = temp.next;
                idx++;
            }

            temp = Head;

            while (idx >= 2) {
                temp = temp.next;
                idx = idx - 1;
            }

            ptr.random = temp;

            curr = curr.next;
            ptr = ptr.next;
        }

        return Head;
    }
}
