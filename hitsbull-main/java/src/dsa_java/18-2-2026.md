# Ques-141 Linked List Cycle Detection (Floyd’s Algorithm)

This Java method checks whether a linked list contains a cycle using the **Floyd’s Tortoise and Hare Algorithm**.

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            
            if (slow == fast) {
                return true;
            }
        }
        
        return false;
    }
}
```

# Ques-142 Detect Cycle in Linked List (Floyd’s Cycle Detection - Start Node)

This Java method detects the **starting node of a cycle** in a linked list.
If no cycle exists, it returns `null`.

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            
            if (slow == fast) {
                slow = head;
                
                while (slow != fast) {
                    slow = slow.next;
                    fast = fast.next;
                }
                
                return slow;
            }
        }
        
        return null;
    }
}
